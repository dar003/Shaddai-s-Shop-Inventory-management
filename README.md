# Shaddai-s-Shop-Inventory-management
Tienda web mobile-first v2.0 para pequeños comercios y emprendimientos, diseñado para consultar productos, filtrar el catálogo, gestionar un carrito de compras e inventario, además de preparar pedidos mediante pagos rápidos efectuados de inmediato vía WhatsApp. Ten la libertad de probarlo y déjame tu opinión!!
